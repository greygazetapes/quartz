# Основы Git

В ходе работы с Git мы меняем рабочее дерево проекта.

* **Рабочее дерево (рабочая директория, или working directory)** - это реальный набор файлов твоего проекта в их текущем состоянии. 

Когда говорят о правках в **рабочем дереве**, то имеют в виду внесенные правки в файл, которые ещё не сохранены в Git.

Представим, что необходимо просмотреть все правки и решить, каких из них будут внесены.

1. **Просмотр правок**

На данном этапе в Git можно просмотреть изменения во всех файлах. После чего выбираются нужные для следующего снимка (коммита) и добавляются в **область подготовки (staging area)**.

**Staging area** - это кратковременная память Git. Здесь записывается, какие изменения выбраны для следующего коммита.

2. **Создание коммита**

Остаётся создать коммит. После создания коммита изменения навсегда сохраняются в репозитории Git).

Одни коммиты могут относиться к основной истории проекта, другие - к экспериментальным веткам, третьи могут оказаться временными (мы их потом удалим). Коммит может быть крошечным или огромным.

Репозиторий хранится в директории `.git` в корне проекта.

3. **Синхронизация локального репозитория с удалённым**

**Push** - отправка изменений в удалённый репозиторий.

**Pull** - получение изменений из удалённого репозитория.
