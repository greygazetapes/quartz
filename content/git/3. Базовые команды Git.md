## Команды `git` и `git help`
`git`- без аргументов просто выводит список доступных команд и опций. 

Это то же самое, что выполнить `git help`. Например, `git help commit` покажет справку по команде `git commit`.

---

## Команда `git config`

**`git config`** - используется для изменения настроек. По умолчанию работает с конфигурацией текущего репозитория. Однако с добавлением флага `--global`, задаётся глобальное значение для всех репозиториев (если только в одном из них настройки не переопределены локально).

**`git config --global user.name "My Name"`** - задание глобального имени. `user.name` - это настройка, которую мы меняем.

**`git config --global user.email "my@email.com"`** - задание глобального email.

*Для чего это нужно?* Далее, когда будут вноситься изменения в репозиторий, Git будет указывать тебя как автора этих изменений.
