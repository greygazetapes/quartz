# Контроль версий (Git)
---
**Система контроля версий (version control system)** - это программа, которая сохраняет историю изменений файлов. Она работает как резервная копия для кода.

Существуют самостоятельные системы контроля версий (Git, Mercurial, Subversion), а также встроенные (например, в Google Docs).

**Git** - система контроля версий.

Систему Git разработал Линус Торвальдс в 2005 году. Он разработал Git для управления кодом ядра Linux. Именно вокруг Git дальше выросли GitHub и GitLab, он также встроен в большинство IDE.
