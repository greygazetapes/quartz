# Мелкие настройки
## Настройка переносов строк
Linux и Windows используют разные коды для переноса используя `Enter`. Это создаёт путаницу при коммитах.

Для этих настроек в Git используются `core.autocrlf` и 'core.safecrlf'.

Вводим команды:
* `git config --global core.autocrlf true`
* `git config --global core.safecrlf warn`
## Настройка имени ветки по умолчанию
Раньше стандартом по умолчанию была ветка `master`. Однако в 2020 году платформы начали менять название по умолчанию на `main`. Это сделали, чтобы убрать любые ассоциации с рабством.

Изменим название ветки на `main`:
* ``git config --global init.defaultBranch main``
